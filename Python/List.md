## 리스트 만들기

여러 값을 순서대로 담는 자료형. 비어 있을 수도 있고, 어떤 자료형이든 섞어서 담을 수 있으며 리스트 안에 리스트를 넣을 수도 있다.

```python
a = []                        # 빈 리스트
b = [1, 2, 3]                 # 숫자
c = ['Life', 'is', 'too']     # 문자열
d = [1, 2, 'Life', 'is']      # 혼합
e = [1, 2, ['Life', 'is']]    # 중첩
f = list()                    # 빈 리스트 (생성자)
```

## 인덱싱

인덱스는 `0`부터 시작하며, 음수 인덱스는 `-1`부터 뒤에서부터 센다.

```python
a = [1, 2, 3]
print(a[0])         # 1  <- 첫 번째 요소
print(a[0] + a[2])  # 4  <- 0번 + 2번
print(a[-1])        # 3  <- 뒤에서 첫 번째
```

- **범위를 벗어난 인덱스는 에러**

  ```python
  a = [1, 2, 3]
  print(a[3])   # IndexError
  print(a[-4])  # IndexError
  ```

- **중첩 리스트는 인덱스를 연달아 붙여 접근한다**

  ```python
  a = [1, 2, 3, ['a', 'b', 'c']]
  print(a[3][0])  # a
  ```

## 슬라이싱

`a[시작:끝]` 형태로 일부 구간을 잘라낸다. **시작은 포함, 끝은 미포함**이다.

```python
a = [1, 2, 3, 4, 5]
print(a[0:2])  # [1, 2]        <- 명시적 범위
print(a[:2])   # [1, 2]        <- 시작 생략(처음부터)
print(a[2:])   # [3, 4, 5]     <- 끝 생략(끝까지)
```

- **중첩 리스트 슬라이싱**

  ```python
  a = [1, 2, 3, ['a', 'b', 'c'], 4, 5]
  print(a[2:5])   # [3, ['a', 'b', 'c'], 4]
  print(a[3][:2]) # ['a', 'b']  <- 3번 요소를 다시 슬라이싱
  ```

## 연산

| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `+` | 리스트 이어 붙이기 | `[1, 2, 3] + [4, 5, 6]` | `[1, 2, 3, 4, 5, 6]` |
| `*` | 리스트 반복 | `[1, 2, 3] * 3` | `[1, 2, 3, 1, 2, 3, 1, 2, 3]` |
| `len()` | 길이 구하기 | `len([1, 2, 3])` | `3` |

```python
a = [1, 2, 3]
b = [4, 5, 6]
print(a + b)    # [1, 2, 3, 4, 5, 6]
print(a * 3)    # [1, 2, 3, 1, 2, 3, 1, 2, 3]
print(len(a))   # 3
```

## 수정과 삭제

- **인덱스로 값 수정**

  ```python
  a = [1, 2, 3]
  a[2] = 4
  print(a)  # [1, 2, 4]
  ```

- **`del` 로 삭제** — 요소 하나 또는 슬라이싱 범위를 지울 수 있다.

  ```python
  a = [1, 2, 3]
  del a[1]
  print(a)  # [1, 3]

  a = [1, 2, 3, 4, 5]
  del a[2:]
  print(a)  # [1, 2]
  ```

## 관련 함수

| 함수 | 의미 | 초기 `a` | 예시 | 결과 |
| --- | --- | --- | --- | --- |
| `append(x)` | 맨 뒤에 요소 추가 | `[1, 2, 3]` | `a.append(4)` | `[1, 2, 3, 4]` |
| `sort()` | 오름차순 정렬 | `[1, 4, 3, 2]` | `a.sort()` | `[1, 2, 3, 4]` |
| `reverse()` | 순서 뒤집기 | `[1, 2, 3, 4]` | `a.reverse()` | `[4, 3, 2, 1]` |
| `index(x)` | 값 `x`의 첫 인덱스 반환 | `[1, 2, 3]` | `a.index(3)` | `2` |
| `insert(i, x)` | `i` 위치에 `x` 삽입 | `[1, 2, 3]` | `a.insert(0, 4)` | `[4, 1, 2, 3]` |
| `remove(x)` | 첫 번째로 나오는 `x` 제거 | `[1, 2, 3, 1, 2, 3]` | `a.remove(3)` | `[1, 2, 1, 2, 3]` |
| `pop()` | 마지막 요소 꺼내고 제거 | `[1, 2, 3]` | `a.pop()` | `3` 반환, `a` → `[1, 2]` |
| `pop(i)` | `i` 위치 요소 꺼내고 제거 | `[1, 2, 3]` | `a.pop(1)` | `2` 반환, `a` → `[1, 3]` |
| `count(x)` | `x`의 개수 세기 | `[1, 2, 3, 1]` | `a.count(1)` | `2` |
| `extend([...])` | 리스트를 이어 붙여 확장 | `[1, 2, 3]` | `a.extend([4, 5])` | `[1, 2, 3, 4, 5]` |

- **`append` 는 어떤 자료형이든 요소 하나로 추가한다**

  리스트를 넣으면 "펼쳐지지 않고" 중첩된 형태로 들어간다.

  ```python
  a = [1, 2, 3]
  a.append(4)       # [1, 2, 3, 4]
  a.append([5, 6])  # [1, 2, 3, 4, [5, 6]]  <- 리스트가 통째로 요소가 됨
  a.append('a')     # [1, 2, 3, 4, [5, 6], 'a']
  ```

- **`sort` 는 정렬할 수 없는 상태면 에러**

  ```python
  a = [2, 'c', 1, 'a']
  a.sort()  # TypeError: 숫자와 문자열은 비교 불가
  ```

- **에러가 나는 경우 정리**

  ```python
  a = [1, 2, 3]
  a.index(10)  # ValueError: 없는 값의 인덱스를 찾을 때
  a.insert(5, 1)  # (범위를 크게 벗어나면 맨 뒤에 붙지만) 없는 값 삭제/pop 은 에러
  a.remove(5)  # ValueError: 없는 값을 제거할 때
  [].pop()     # IndexError: 빈 리스트에서 꺼낼 때
  ```

- **`extend` 는 `+=` 연산과 같다**

  `append` 와 달리 리스트의 각 요소가 펼쳐져서 붙는다.

  ```python
  a = [1, 2, 3]
  a.extend([4, 5])
  print(a)  # [1, 2, 3, 4, 5]

  a = [1, 2, 3]
  a += [4, 5]
  print(a)  # [1, 2, 3, 4, 5]
  ```
