## 튜플 만들기

리스트와 비슷하지만 `()` 소괄호로 묶는다. 괄호를 생략하고 값만 나열해도 튜플이 된다.

```python
t1 = ()                       # 빈 튜플
t2 = (1,)                     # 요소 1개 (쉼표 필수)
t3 = (1, 2, 3)                # 여러 개
t4 = 1, 2, 3                  # 괄호 생략도 가능
t5 = ('a', 'b', ('ab', 'cd')) # 중첩
```

- **요소가 하나일 때는 쉼표를 꼭 붙여야 한다**

  `(1)`은 그냥 숫자 `1`이고, `(1,)`이라야 튜플이다.

  ```python
  a = (1)   # int  <- 튜플이 아님
  b = (1,)  # tuple
  ```

## 리스트와의 차이

가장 큰 차이는 **튜플은 값을 바꿀 수 없다(불변, immutable)** 는 점이다. 요소를 삭제하거나 수정하려 하면 에러가 난다.

```python
t1 = (1, 2, 'a', 'b')
del t1[0]    # TypeError: 삭제 불가
t1[0] = 'c'  # TypeError: 수정 불가
```

| | 리스트(List) | 튜플(Tuple) |
| --- | --- | --- |
| 기호 | `[ ]` | `( )` |
| 값 변경 | 가능 | 불가능(불변) |
| 용도 | 값이 바뀌는 데이터 | 바뀌면 안 되는 데이터 |

## 인덱싱과 슬라이싱

값을 읽는 방식(인덱싱, 슬라이싱)은 리스트와 동일하다.

```python
t1 = (1, 2, 'a', 'b')
print(t1[0])   # 1
print(t1[3])   # b
print(t1[4])   # IndexError <- 범위 초과

print(t1[1:])  # (2, 'a', 'b')  <- 슬라이싱 결과도 튜플
```

## 연산

`+`, `*`, `len()` 은 리스트와 똑같이 동작한다.

| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `+` | 튜플 이어 붙이기 | `(1, 2) + (3, 4)` | `(1, 2, 3, 4)` |
| `*` | 튜플 반복 | `(3, 4) * 3` | `(3, 4, 3, 4, 3, 4)` |
| `len()` | 길이 구하기 | `len((1, 2, 'a', 'b'))` | `4` |

```python
t1 = (1, 2, 'a', 'b')
t2 = (3, 4)

print(t1 + t2)  # (1, 2, 'a', 'b', 3, 4)
print(t2 * 3)   # (3, 4, 3, 4, 3, 4)
print(len(t1))  # 4
```

> `+` 와 `*` 는 기존 튜플을 바꾸는 게 아니라 **새 튜플을 만들어 반환**한다. 그래서 불변이라도 사용할 수 있다.
