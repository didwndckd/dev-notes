## 기본 구조

주어진 조건이 참인지 거짓인지 판단해 흐름을 나누는 문법이다. `if` → `elif` → `else` 순으로 조건을 위에서부터 검사하며, 참인 블록을 만나면 그 블록만 실행하고 나머지는 건너뛴다.

```python
if bool(조건):
    실행 코드
elif bool(조건):   # 이전 조건이 거짓일 때 검사, 개수 제한 없음
    실행 코드
else:              # 위 조건이 모두 거짓일 때 실행
    실행 코드
```

```python
# 돈이 10000원 이상이면 택시, 1000원 이상이면 버스, 그 아래는 걸어간다.
money = 10000
if money >= 10000:
    print("택시")
elif money >= 1000:
    print("버스")
else:
    print("뚜벅")
# 택시
```

- 조건문 뒤에는 항상 콜론(`:`)이 붙는다. (`while`, `for`, `def`, `class`도 동일)
- `elif`, `else`는 `if` 없이 단독으로 쓸 수 없다.

## 들여쓰기

조건에 속하는 문장은 모두 들여쓰기해야 하며, **같은 블록 안에서는 들여쓰기 깊이가 모두 같아야** 한다. (Python 커뮤니티는 공백 4칸을 권장)

```python
if True:
    print("1")
# print("2")   # Error: 들여쓰기를 하지 않음
    print("3")
        # print("4")   # Error: 들여쓰기를 더 함
else:
        print("1")     # 블록이 다르면 깊이가 달라도 됨
        print("2")
```

> 들여쓰기 깊이를 맞추는 기준은 "해당 조건에 속하는 블록"이다. 서로 다른 블록(`if` 블록과 `else` 블록)끼리는 깊이가 달라도 문제없다.

## 조건에 들어갈 수 있는 것

조건 자리에는 결국 `bool`(참/거짓) 값이 들어간다. 이 값을 만드는 방법에는 여러 가지가 있다.

| 구분 | 연산자 |
| --- | --- |
| 비교 연산자 | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| 논리 연산자 | `and`, `or`, `not` |
| 포함 여부 | `in`, `not in` |

- **논리 연산자**

  | 연산자 | 설명 |
  | --- | --- |
  | `x or y` | 둘 중 하나만 참이어도 참 |
  | `x and y` | 둘 다 참이어야 참 |
  | `not x` | `x`가 거짓이면 참 |

- **in / not in**

  리스트, 튜플, 문자열, 집합, 딕셔너리 등에 해당 데이터가 있는지 검사한다.

  ```python
  1 in [1, 2, 3]       # True
  1 not in [1, 2, 3]   # False
  1 in (1, 2, 3)       # True
  "1" in "123"         # True
  1 in set([1, 2, 3])  # True
  'a' in {'a': 1}      # True: 딕셔너리는 키를 기준으로 검사
  1 in {'a': 1}        # False: 값이 아닌 키를 보므로 False
  ```

## pass

해당 조건에서 아무것도 하지 않고 넘어가고 싶을 때 사용한다. 블록을 비워 두면 오류가 나기 때문에 자리를 채우는 용도로 넣는다.

```python
pocket = ['money', 'paper', 'cellphone']
if 'money' in pocket:
    pass   # 아무것도 하지 않음
else:
    print("뚜벅")
```

## 한 줄로 작성하기

수행할 문장이 한 줄이면 콜론(`:`) 바로 뒤에 문장을 이어서 쓸 수 있다.

```python
if 'card' in pocket: pass
else: print("뚜벅")
```

## 조건부 표현식(삼항 연산자)

조건에 따라 변수에 서로 다른 값을 대입하는 간단한 분기는 한 줄로 줄일 수 있다.

```python
변수 = 참일_때_값 if 조건 else 거짓일_때_값
```

```python
score = 85
result = "합격" if score >= 60 else "불합격"  # result → "합격"
```

위 코드는 아래 `if-else`와 완전히 동일하다.

```python
if score >= 60:
    result = "합격"
else:
    result = "불합격"
```

> 코드를 간결하게 해 주지만, 조건이 복잡하거나 표현식이 길면 오히려 가독성이 떨어지므로 간단한 경우에만 쓰는 것이 좋다.

## 비교 연산자의 연쇄 사용

수학에서처럼 비교 연산자를 이어서 쓸 수 있다.

```python
x = 5
1 < x < 10     # True: 1 < x 이고 x < 10
10 <= x <= 20  # False
```

`1 < x < 10`은 아래와 같은 의미이다.

```python
(1 < x) and (x < 10)  # True
```

## match-case 문

- Python 3.10부터 사용 가능
- `match` 뒤의 값과 `case` 값을 위에서부터 `==`로 비교하다가, 일치하는 첫 `case`를 실행한다.
- `case _`는 어떤 case에도 맞지 않을 때 실행되는 와일드카드(`if-else`의 `else` 역할)이며 생략할 수 있다.

```python
grade = 'B'
match grade:
    case 'A':
        print("탁월한 성적입니다.")
    case 'B':
        print("우수한 성적입니다.")
    case 'C':
        print("보통입니다.")
    case _:   # 생략 가능
        print("노력이 필요합니다.")
# 우수한 성적입니다.
```

- **여러 패턴을 하나의 case에서 처리하기**

  `|` 기호로 여러 값을 하나의 `case`에 지정할 수 있다.

  ```python
  match grade:
      case 'A' | 'B' | 'C':
          print("합격입니다.")
      case _:
          print("불합격입니다.")
  # 합격입니다.
  ```
