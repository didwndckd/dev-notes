## 변수 만들기

`=` 기호로 값을 저장한다. C나 Java와 달리 **자료형을 직접 지정하지 않아도** 파이썬이 값을 보고 알아서 판단한다.

```python
a = 1
b = "python"
c = [1, 2, 3]
```

## 변수 명명 규칙

| 규칙 | 설명 |
| --- | --- |
| 사용 가능 문자 | 영문자, 숫자, 언더스코어(`_`) |
| 숫자로 시작 불가 | `1name` (오류) |
| 예약어 사용 불가 | `if = 10` (오류) |
| 대소문자 구분 | `userName` 과 `username` 은 다른 변수 |

```python
# 올바른 변수명
name = "홍길동"
user_name = "gildong"
userName = "gildong"   # 카멜 케이스
_private = "비공개"
count1 = 10

# 잘못된 변수명
1name = "홍길동"    # 숫자로 시작 (오류)
user-name = "홍길동" # 하이픈 사용 (오류)
if = 10            # 예약어 사용 (오류)
```

- **파이썬 예약어** — 아래 단어들은 특별한 의미를 가지므로 변수명으로 쓸 수 없다.

  ```
  False, None, True, and, as, assert, break, class, continue, def,
  del, elif, else, except, finally, for, from, global, if, import,
  in, is, lambda, nonlocal, not, or, pass, raise, return, try,
  while, with, yield
  ```

- **권장 사항** — 규칙은 아니지만 지키면 좋은 관례
  - 의미가 명확한 이름을 쓴다. (`a` 보다 `student_name`)
  - 단어 사이는 `snake_case`(언더스코어)를 권장한다.
  - 너무 짧거나 너무 긴 이름은 피한다.

## 변수란? (객체와 참조)

파이썬에서 변수는 **객체를 가리키는 이름표**다. `a = [1, 2, 3]` 이라고 하면 `[1, 2, 3]` 리스트 객체가 메모리에 생성되고, `a` 는 그 객체가 저장된 **메모리 주소를 가리킨다.**

`id()` 함수로 변수가 가리키는 객체의 주소를 확인할 수 있다.

```python
a = [1, 2, 3]
print(id(a))  # 4303029896  <- 실행할 때마다 값이 다름
```

## 객체 복사와 참조

가장 헷갈리는 부분이다. **변수를 그냥 대입하면 값이 아니라 주소가 복사**되어 같은 객체를 가리키게 된다. (아래는 리스트로 설명하지만 모든 객체에 해당한다)

```python
a = [1, 2, 3]
b = a          # a의 주소를 b에 대입 -> 같은 객체를 가리킴

print(id(a))   # 4341583744
print(id(b))   # 4341583744  <- 주소가 같음
print(a is b)  # True

a[1] = 4       # a를 바꿨는데...
print(a)       # [1, 4, 3]
print(b)       # [1, 4, 3]  <- b도 같이 바뀜!
```

> `is` 는 두 변수가 **같은 객체를 가리키는지** 판단한다.

`a` 와 다른 주소를 가리키도록 값만 복사하려면 다음 방법을 쓴다. 세 가지 모두 결과가 같다.

| 방법 | 코드 | 비고 |
| --- | --- | --- |
| 전체 슬라이싱 | `b = a[:]` | 별도 모듈 불필요 |
| 리스트 자체 함수 | `b = a.copy()` | 별도 모듈 불필요 |
| copy 모듈 | `b = copy(a)` | `from copy import copy` 필요 |

```python
a = [1, 2, 3]
b = a[:]       # 값을 읽어서 새 객체로 복사
a[1] = 4

print(a)       # [1, 4, 3]
print(b)       # [1, 2, 3]  <- b는 그대로
print(a is b)  # False  <- 서로 다른 객체
```

> 별도 모듈이 필요 없는 `b = a[:]` 또는 `b = a.copy()` 를 주로 쓴다.

- **이 문제는 mutable 객체에서만 드러난다.** "안 바꾼 변수도 같이 바뀌는" 현상은 값을 **제자리에서 바꿀 수 있는** 리스트·딕셔너리·집합에서 나타난다. 딕셔너리도 똑같고, `.copy()` 로 복사한다.

  ```python
  a = {'x': 1}
  b = a
  a['x'] = 99
  print(b)  # {'x': 99}  <- b도 같이 바뀜

  b = a.copy()  # 딕셔너리/집합도 .copy() 로 복사
  ```

- **불변(immutable) 객체는 이 문제가 없다.** `int`, `str`, `tuple` 은 제자리 수정 자체가 불가능해서, 값을 바꾸면 새 객체가 생긴다. 따라서 다른 변수에 영향을 주지 않는다.

  ```python
  a = 1
  b = a
  a = 2       # a에 새 객체를 다시 대입
  print(b)    # 1  <- b는 영향 없음
  ```

## 변수를 만드는 여러 가지 방법

- **튜플/리스트로 여러 변수에 한 번에 대입** — 괄호는 생략할 수 있다.

  ```python
  a, b = ('python', 'life')
  (a, b) = 'python', 'life'
  a, b = 'python', 'life'      # 괄호 생략
  [a, b] = ['python', 'life']  # 리스트로도 가능
  # a -> 'python', b -> 'life'
  ```

- **여러 변수에 같은 값 대입**

  ```python
  a = b = 'python'
  # a -> 'python', b -> 'python'
  ```

- **두 변수의 값 바꾸기(swap)** — 임시 변수 없이 한 줄로 처리된다.

  ```python
  a = 3
  b = 5
  a, b = b, a
  print(a)  # 5
  print(b)  # 3
  ```

  > 다른 언어는 보통 임시 변수가 필요하지만, 파이썬은 `a, b = b, a` 로 간단히 교환할 수 있다.
