## 정수형(int)

정수를 표현하는 자료형. 양의 정수, 음의 정수, 0을 모두 포함한다.

```python
a = 123
a = -178
a = 0
```

Python3의 `int`는 크기 제한이 없다. (메모리가 허용하는 한 얼마든지 큰 수를 담을 수 있음)

## 실수형(float)

소수점이 포함된 숫자.

```python
a = 1.2
a = 3.45
```

- **지수 표현(e, E)**

  `e` 또는 `E` 뒤의 숫자는 10의 지수를 의미한다. (`aEn` == `a * 10^n`)

  ```python
  a = 4.24E10   # 4.24 * 10^10 = 42400000000.0
  a = 4.24e-10  # 4.24 * 10^-10 = 4.24e-10
  ```

  대문자/소문자 어느 쪽을 써도 동일하며, 지수 표현을 쓰면 결과는 항상 `float`이다.

## 진수 표현

| 진수 | 접두사 | 예시 | 10진수 값 |
| --- | --- | --- | --- |
| 2진수 | `0b` | `0b1111` | 15 |
| 8진수 | `0o` | `0o177` | 127 |
| 16진수 | `0x` | `0x8ff` | 2303 |

```python
a = 0o177
print(a)  # 127

a = 0x8ff
print(a)  # 2303
```

> 접두사는 "표기 방식"일 뿐이며 저장되는 값은 그냥 `int`다. 그래서 `print` 하면 10진수로 출력된다.

## 연산자

```python
a = 3
b = 4
```

| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `+` | 덧셈 | `a + b` | `7` |
| `-` | 뺄셈 | `a - b` | `-1` |
| `*` | 곱셈 | `a * b` | `12` |
| `/` | 나눗셈 | `a / b` | `0.75` |
| `**` | 제곱 | `a ** b` | `81` (3^4) |
| `%` | 나머지 | `7 % 3` | `1` |
| `//` | 몫(버림 나눗셈) | `7 // 4` | `1` |

- **나눗셈(`/`)은 항상 `float`을 반환한다**

  ```python
  print(7 / 4)   # 1.75
  print(8 / 4)   # 2.0  <- 나누어 떨어져도 float
  ```

- **나머지(`%`)**

  ```python
  print(7 % 3)   # 1
  print(3 % 7)   # 3  <- 나누는 수가 더 크면 피연산자가 그대로 나머지
  ```

- **몫(`//`)**

  `/` 결과에서 소수점 아래를 버린다.

  ```python
  print(7 / 4)   # 1.75
  print(7 // 4)  # 1
  ```

## 복합 대입 연산자

`a = a + 1` 처럼 자기 자신을 연산해 다시 할당하는 코드는 `+=` 로 줄여 쓸 수 있다.

```python
a = 1
a = a + 1
print(a)  # 2

a = 1
a += 1
print(a)  # 2
```

| 연산자 | 의미 | 예시 | 동일한 코드 |
| --- | --- | --- | --- |
| `+=` | 더한 후 할당 | `a += 1` | `a = a + 1` |
| `-=` | 뺀 후 할당 | `a -= 1` | `a = a - 1` |
| `*=` | 곱한 후 할당 | `a *= 2` | `a = a * 2` |
| `/=` | 나눈 후 할당 | `a /= 2` | `a = a / 2` |
| `//=` | 몫을 할당 | `a //= 2` | `a = a // 2` |
| `%=` | 나머지를 할당 | `a %= 2` | `a = a % 2` |
| `**=` | 제곱한 후 할당 | `a **= 2` | `a = a ** 2` |

> Python에는 `a++`, `a--` 같은 증감 연산자가 없다. `a += 1` 을 써야 한다.
