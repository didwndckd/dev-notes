## 집합 만들기

수학의 집합과 같은 자료형. `set()` 에 리스트·문자열을 넣거나 `{}` 로 만든다.

```python
s1 = set([1, 2, 3, 4])  # 리스트 기반 -> {1, 2, 3, 4}
s2 = set("Hello")       # 문자열 기반 -> {'e', 'o', 'l', 'H'}
s3 = {1, 2, 3}          # 중괄호로 직접 -> {1, 2, 3}
s5 = set()              # 빈 집합 -> set()
```

- **빈 집합은 `set()` 으로 만든다.** `{}` 는 빈 딕셔너리이므로 집합이 아니다.

  ```python
  a = {}      # dict
  b = set()   # set
  ```

## 특징

- **중복을 허용하지 않는다** — 같은 값은 하나만 남는다. (`set("Hello")` 의 `l` 이 하나뿐인 이유)
- **순서가 없다** — 인덱싱/슬라이싱이 불가능하고, 출력 순서도 입력 순서와 다를 수 있다.

```python
print(set([1, 1, 2, 2, 3]))  # {1, 2, 3}  <- 중복 제거
print(set("Hello"))          # {'e', 'o', 'l', 'H'}  <- 순서 보장 안 됨
```

> 이 "중복 제거" 특성 때문에 리스트의 중복을 없앨 때 `set()` 을 자주 쓴다.

## 리스트·튜플로 변환

집합은 인덱싱이 안 되므로, 순서가 필요하면 리스트나 튜플로 변환해서 쓴다.

```python
s1 = set([1, 2, 3])
print(list(s1))   # [1, 2, 3]
print(tuple(s1))  # (1, 2, 3)
```

## 교집합·합집합·차집합

연산자와 메서드 두 방식 모두 같은 결과를 낸다.

```python
s1 = set([1, 2, 3, 4, 5, 6])
s2 = set([4, 5, 6, 7, 8, 9])
```

| 연산 | 연산자 | 메서드 | 결과 |
| --- | --- | --- | --- |
| 교집합 | `s1 & s2` | `s1.intersection(s2)` | `{4, 5, 6}` |
| 합집합 | `s1 \| s2` | `s1.union(s2)` | `{1, 2, 3, 4, 5, 6, 7, 8, 9}` |
| 차집합 | `s1 - s2` | `s1.difference(s2)` | `{1, 2, 3}` |
| 차집합 | `s2 - s1` | `s2.difference(s1)` | `{7, 8, 9}` |

> 차집합은 방향에 따라 결과가 다르다. `s1 - s2` 는 s1에만 있는 값이다.

## 관련 함수

아래 표는 모두 다음 초기 상태에서 시작한다.

```python
s1 = set([1, 2, 3])
```

| 함수 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `add(x)` | 값 하나 추가 | `s1.add(4)` | `{1, 2, 3, 4}` |
| `update([...])` | 값 여러 개 추가 | `s1.update([4, 5, 6])` | `{1, 2, 3, 4, 5, 6}` |
| `remove(x)` | 특정 값 제거 | `s1.remove(2)` | `{1, 3}` |
| `discard(x)` | 특정 값 제거 | `s1.discard(2)` | `{1, 3}` |
| `clear()` | 모든 값 제거 | `s1.clear()` | `set()` |

- **`remove` 와 `discard` 의 차이** — 둘 다 값을 제거하지만, 없는 값을 지울 때 동작이 다르다.

  ```python
  s1 = set([1, 2, 3])
  s1.remove(4)   # KeyError: 없는 값이면 에러

  s1 = set([1, 2, 3])
  s1.discard(4)  # 없는 값이어도 에러 없이 그냥 넘어감
  print(s1)      # {1, 2, 3}
  ```
